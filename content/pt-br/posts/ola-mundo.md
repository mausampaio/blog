## Por que um blog

Depois de anos guardando anotações em arquivos soltos, resolvi juntar tudo em um lugar
público. A ideia é simples: escrever sobre o que ando aprendendo, principalmente em
desenvolvimento de software.

Escrever obriga a organizar o pensamento. Quando você precisa explicar algo para outra
pessoa, descobre rapidamente os buracos no próprio entendimento.

## O que esperar

Alguns temas que devem aparecer por aqui:

- Desenvolvimento de software no dia a dia
- Ferramentas e automações que me economizam tempo
- Anotações de estudo, o famoso "eu do futuro vai agradecer"

## Como este blog foi feito

O site é estático, gerado com [Hugo](https://gohugo.io/) e o tema
[PaperMod](https://github.com/adityatelange/hugo-PaperMod), hospedado no GitHub Pages.
O deploy acontece automaticamente a cada push na branch `main`.

Um exemplo de bloco de código, só para ver como fica:

```go
package main

import "fmt"

func main() {
    fmt.Println("Olá, mundo")
}
```

É isso. Até o próximo.
